# Steam achievement art: style proposals (awaiting the owner's choice)

Three styles, each shown on the same three achievements (Halfway Up `ACH_TOWER_5`, Gravity: 1, You: 0
`ACH_FIRST_FALL`, Express Elevator `ACH_SPEED_SUMMIT`), unlocked and locked:

- `style_A.png`: Sky Diorama (soft 3D renders in the game's world skies, gold and brown frame)
- `style_B.png`: Pixel Emblem (64-pixel art in a gold octagon, title lettering, padlock when locked)
- `style_C.png`: Sticker Badge (round sticker, sunburst per category, ribbon with the name)

The `style_*_ACH_*.png` files are the 18 individual 256 x 256 icons. Every sheet also shows them at the sizes Steam uses
(64, 48 and 32 pixels) and in a mock Steam achievement list.

Made by `tools/achievements/make_concepts.py` from renders of the game's own models (`tools/achievements/renders/`,
made with the desktop IconShot tool: the hero is the Quaternius character and the castle, star, cloud and flag come
from the Quaternius Ultimate Platformer Pack; the platform is the Kenney block; all CC0) and the game's own pixel
lettering. The full set of 27 is made only after a style is approved.
